화면을 다시 짰습니다
— 게임처럼

1차 시안은 기존 구성을 그대로 두고 스타일만 정리한 안이었습니다. 이번엔 파티게임의 진행 방식을 기준으로 구조를 바꿨습니다. 핵심 전제: 손에 든 화면은 사회자의 조작기이고, 큰 화면은 방 전체가 보는 무대입니다. 이 둘은 정보량이 달라야 합니다.

준비 시간 단축
모드 → 팀 → 게임 → 라운드, 4화면을 로비 1화면으로. 시작까지 탭 2번.
읽지 않는 타이머
숫자를 읽는 대신 줄어드는 기둥으로. 방 뒤에서도 남은 시간이 보입니다.
진행이 보이는 눈금
‘12 / 30’ 텍스트 대신 성공·패스 눈금. 성적표가 실시간으로 쌓입니다.
차례 넘김 = 이벤트
결과 모달 대신 순위 변동 → 다음 팀 전면 카드. 흐름이 끊기지 않습니다.

Turn 1 · 스타일 정리안 (기존 구성 유지)

로운네 파티게임
디자인 개선 시안

3D 입체 버튼·무지개 그라데이션·직접 그린 아바타를 걷어내고, 따뜻한 크림 지면 위에 한 개의 강조색 + 게임별 뮤트 컬러로 정리했습니다. 게임별 색 구분과 두 테마는 그대로 유지하되 톤만 낮췄습니다.

01 SURFACE
그라데이션 카드 → 크림 지면 + 단색 면. 입체 버튼의 5px 하단 그림자를 없애고 눌림은 톤 변화로 표현.
02 ICON
직접 그린 삽화 → 라인 아이콘 한 세트(굵기 2.75)로 통일. 카드마다 색 타일 1개만.
03 AVATAR
동물 그림 → 팀 색 + 이니셜 모노그램. 캐릭터의 재미는 추천 팀 이름에 남깁니다.
04 TYPE
제목·제시어는 GmarketSans, 본문은 Pretendard, 숫자는 Outfit 고정폭. 3단계 크기만 사용.
