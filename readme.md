# 로운네 파티게임 (Premium)

가족·친구·워크샵 모임에서 즐기는 한국어 파티 게임 모음. 모바일 · 태블릿 · 데스크탑 브라우저에서 앱처럼 동작합니다.

## 포함 게임

- **스피드 게임** — 설명 없이 단어 맞추기 (60/90/120초, 라운드당 최대 30문제)
- **몸으로 말해요** — 액션으로 단어 전달 (라운드당 최대 25문제)
- **초성 퀴즈** — 자동 힌트 시스템 (라운드당 최대 12문제)
- **이어서 말해요** — 주제 추첨 후 릴레이 (난이도 선택: 순한맛/보통/매운맛 · 재추첨 1회)
- **네 글자 퀴즈** — 목표 개수 연속 성공

시간제 게임은 주제와 관계없이 라운드당 출제 수가 같아 **만점(출제 수 × 배점)이 모든 팀에게 동일**합니다.

## 디자인 & 사운드

- **두 가지 컬러 테마** — 파티 모드(따뜻한 코랄), 워크샵 모드(비비드 블루). 모드 선택 시 자동 전환
- **팀 캐릭터 10종** — 오리지널 동물 아바타(여우·판다·토끼·고양이·강아지·병아리·개구리·곰·펭귄·유니콘)가 팀마다 랜덤 배정되고 팀 이름도 자동 추천 (주사위 버튼으로 다시 뽑기, 이름은 자유 수정)
- **폰트 시스템** — GmarketSans(제목·제시어) + Pretendard(본문) + Outfit(숫자·영문 라벨)
- **게임 사운드** — 모든 효과음이 C장조 펜타토닉으로 통일된 신스 사운드 (연속 정답 시 음정 상승 콤보, 팡파레 케이던스, 카운트다운 톤 상승, lo-fi 스윙 BGM)
- iPhone 노치·홈바(safe-area), iPad 2단 레이아웃, 가로 모드 압축 레이아웃 대응

## 파일 구조

```
.
├── index.html             # 메인 앱 (게임 로직 + 사운드 엔진)
├── styles.css             # 디자인 시스템 (두 테마 토큰 포함)
├── questions.js           # ★ 문제 데이터 (문제 수정은 이 파일만)
├── characters.js          # 팀 캐릭터 아바타 + 팀 이름 추천 풀
├── tools/validate.js      # 문제 데이터 검증 도구
├── netlify.toml           # Netlify 설정 (CLI/Git 배포용)
├── _redirects             # SPA 리다이렉트 + _backup 접근 차단 (Drop 배포용)
├── _headers               # 캐시/보안 헤더 (Drop 배포용)
├── manifest.webmanifest   # PWA 매니페스트 (홈 화면 추가용)
└── _backup/               # 구버전 원본 보관 (배포돼도 URL 접근 차단됨)
```

## 문제 수정 방법 (중요)

1. `questions.js` 를 텍스트 편집기로 열어 수정
   - 초성 퀴즈: `{q:초성, a:정답, h:힌트}` — **q는 a의 실제 초성과 일치해야 함**
   - 네 글자 퀴즈: `{q:앞 두 글자, a:뒤 두 글자}`
   - 이어서 말해요: `{q:주제, d:난이도}` — d는 1(순한맛)/2(보통)/3(매운맛). 기본 추첨은 '보통'이라 **d:3 주제는 매운맛 선택 시에만 등장**
   - 스피드/몸으로: 문자열 배열
2. 수정 후 반드시 검증 (초성 오류·중복·글자 수를 자동 검사):
   ```bash
   node tools/validate.js
   ```
3. `✓ 오류 0건` 확인 후 재배포

## Netlify 배포 방법

### 방법 1 — Netlify Drop (가장 간단, 1분 소요)

1. [https://app.netlify.com/drop](https://app.netlify.com/drop) 접속
2. 이 폴더 전체를 드래그 앤 드롭
3. 자동으로 URL이 발급됨 (`https://랜덤이름.netlify.app`)
4. 발급된 URL을 모바일에서 열고 "홈 화면에 추가" → 앱처럼 사용

### 방법 2 — Netlify CLI

```bash
npm install -g netlify-cli
netlify deploy --prod --dir .
```

### 방법 3 — Git 연동 (자동 재배포)

1. GitHub 등에 이 폴더를 push
2. Netlify 대시보드 → "Add new site" → "Import an existing project"
3. 저장소 선택, 빌드 명령은 비워두고 publish directory를 `.` 으로
4. Deploy 클릭

## 배포 후 확인

- `index.html`, `styles.css`, `questions.js`, `characters.js`, `_redirects`, `_headers`, `manifest.webmanifest`가 모두 루트에 있어야 합니다
- 첫 화면이 보이면 어떤 버튼이든 한 번 눌러주세요 → 사운드 엔진 초기화 (BGM은 첫 터치 후 시작)
- iOS Safari에서 "홈 화면에 추가"하면 전체화면 앱처럼 동작합니다
- 사운드(Tone.js)·폭죽(confetti)은 CDN에서 로드됩니다 — 차단된 네트워크에서는 효과만 생략되고 게임은 정상 동작

## 키보드 단축키 (데스크탑)

| 키 | 동작 |
|----|------|
| → 또는 Enter | 성공 / 정답 |
| ← 또는 Space | Pass / 실패 |
| Esc | 게임 중단 (결과 모달에서는 무시됨) |

## 점수 / 진행 상태 초기화

화면 우상단 톱니바퀴 → "처음으로" 또는 브라우저 시크릿창 사용

> 참고: 저장 키가 `partygame_v27`로 변경되어, 이번 버전 배포 후 기존 방문자의 이전 점수는 초기화됩니다 (팀 캐릭터 데이터 추가 때문).
